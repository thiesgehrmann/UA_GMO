# UA_GMO

This repository contains the analysis files for the article, titled "Public perceptions of microbial factories and their applications in synthetic biology", by Ilke Van Tente, Thies Gehrmann, Maarten Boon, Christina Stadlbauer, Rob Lavigne, Kevin J. Verstrepen, Eveline Peeters, Vitor Bernardes Pinheiro, Marjan De Mey, Sarah Lebeer, Irina Spacova and Kristien Hens.

Survey data can be found in the `data` folder.

Code can be found in the `code` folder.
  * `20261005 r script figure 3.R` : R code to generate figure 3
  * `20261005 r script figure 4.R` : R code to generate figure 4
  * `analysis.ipynb` : Jupyter Notebook (Python) that performs the analysis and other visualisations for the paper. Includes other approaches not reported in the paper.

Results (figures) can be found in the `results` folder.
